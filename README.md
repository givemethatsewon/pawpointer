# [🐾 Play Paw Pointer → pawpointer.app](https://pawpointer.app)

Move. Pause. Paw. Real cats point their paws at your cursor.

No sign-up. Just cats.

## How to play

- **Desktop:** Move your cursor, then hold still.
- **Mobile:** Tap anywhere.
- **Keyboard:** Use arrow keys to move the target. Press Space for another cat.

## Run locally

Node.js 22.18+ or 24+.

```sh
npm ci
npm run dev
```

Built with React, TypeScript, and Vite. Hosted on Cloudflare Pages.
